# 安全邊界

## 信任邊界

使用者可在 `neo-fd-desktop/src/components/ScanSidebar.vue` 輸入任意掃描路徑，也可透過資料夾選擇介面選取路徑。前端將路徑、正則規則及結果上限交給 `neo-fd-desktop/src/api/ipc.ts`，再由 `neo-fd-desktop/src-tauri/src/lib.rs` 執行檔案系統操作。

掃描器會讀取使用者指定目錄中的檔案；讀取命令、寫入命令與刪除命令均接收前端傳入的檔案路徑。內容檢視器會在畫面中顯示匹配內容，並允許使用者編輯後寫回或確認永久刪除檔案。

## 已確認的防護與暴露面

- 掃描器略過被判定為二進位的檔案，單行讀取上限為 65,536 位元組。
- 內容讀取命令拒絕非檔案路徑，並拒絕超過 5 MB 的檔案。
- 前端刪除流程有明確確認對話框；原生刪除命令本身只檢查路徑存在且為檔案。
- `neo-fd-desktop/src-tauri/capabilities/default.json` 的外部開啟權限包含 `$HOME/**`、`$HOME/*` 與 `/**` 路徑範圍。
- `neo-fd-desktop/src-tauri/tauri.conf.json` 的內容安全政策欄位目前為 `null`。
- `neo-fd-desktop/src-tauri/src/scanner.rs` 對單一檔案錯誤採略過策略，不會因單一檔案失敗中斷整體掃描。
- `tests/backend/e2e/filesystem.rs` 使用系統暫存目錄驗證檔案服務，不使用專案或使用者資料；測試資料由測試生命週期清理。
- `tests/frontend/e2e/` 的 IPC 模擬只在瀏覽器測試頁面初始化時建立，不會修改產品執行期原始碼。
- 目前檢視的前端與原生程式碼未發現網路 API 呼叫；此結論不代表尚未檢視的工作流或外部執行環境不存在網路行為。

## 未確認事項

- 尚未定義正式威脅模型、敏感資料保存政策、權限最小化政策或稽核記錄要求。
- 後端寫入與刪除命令沒有獨立的使用者確認或路徑範圍限制。
- 發布簽署、憑證保存與產物完整性驗證依工作流環境設定，專案中沒有完整安全程序文件。
- 尚無自動安全掃描或針對檔案權限、符號連結與競態條件的測試。
